一把不會被「加甘草」騙過的中醫方劑評測尺。行業現狀:中醫大模型基準或以藥理問答為主

已作廢,見 VERIFICATION_REPORT §六)。本基準以**雙經典文本仲裁**為地基:

## 評測協議(三口徑)

1. **Base**:模型直接答方名/組成,對註冊表嚴格匹配(同義詞懲罰規則公開);
2. **Audit-L1(積極)**:允許證型歸位(逍遙散類歸經方對應證);
3. **Audit-L2(保守)**:僅變體歸一,寧可不歸位。

**反作弊條款**:命中函數不得包含萬能匹配(甘草/調和藥排除,基線全零報警);
提名層與審計層必須分離(混合架構);提交者須公開命中函數代碼。

## 已知陷阱(給後來者)

- 舊 SymMap 基準因「甘草萬能匹配」作廢(v12 復算:200/200 由追加甘草產生);
